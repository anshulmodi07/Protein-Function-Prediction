DeepProteinHybrid: Custom Architecture Summary

100% Custom PyTorch Model

Unlike generic models, DeepProteinHybrid is trained completely from scratch without external pre-trained representations. It resolves the 5 major failure modes of previous protein function predictors:

1. Inductive Biophysical Priors

Every residue is embedded alongside 6 physical constants: Kyte-Doolittle hydropathy, net charge at physiological pH 7.4, isoelectric point (pI), molecular weight, aromaticity, and polarity.

2. Channel-Wise LayerNorm

Replaces standard BatchNorm1d. Normalizes across channels at each sequence coordinate independently, making representations 100% immune to padding token contamination.

3. Multi-Scale Convolutions + SE

Parallel branches with kernel sizes 3, 5, 9, 15 capture micro-motifs, while Squeeze-and-Excitation (SE) channel attention dynamically recalibrates filter importance.

4. Bidirectional GRU Tertiary Context

Propagates long-range sequential dependencies across all 1,000 sequence positions, enabling the model to capture 3D active site formation between distant linear residues.

5. Asymmetric Loss (ASL)

Dynamically discounts easy background negatives without inflating positive gradients, preserving well-calibrated output probabilities.

6. Per-Class Calibration (τc*)

40 independent validation-calibrated decision thresholds prevent rare enzyme functions from being starved by high-frequency terms.
